# Hi, I'm Developer 👋

**Node.js & C#/.NET backend developer who turns messy, manual problems into reliable, scalable solutions on Microsoft Azure.**

I build APIs and backend services with Node.js and C#/.NET, and I ship them on Microsoft Azure with automated pipelines, security scanning, and sensible rollback plans.

---

## 🛠️ What I work on

- 🟢 **Node.js backends**: REST APIs with Express, MongoDB data layers, and MERN stack projects
- ☁️ **Azure**: Container Apps, Application Insights, Azure OpenAI, and AI Foundry
- 🏗️ **Infrastructure as Code**: environments provisioned with **Bicep**
- 🔄 **CI/CD**: multi-environment pipelines (DEV → SQA → UAT → PRD) in **Azure DevOps** with approval gates and build-number-based rollback
- 🔐 **DevSecOps**: container image scanning with **Trivy** and code quality checks with **SonarQube**
- 📈 **Scalability**: event-driven autoscaling with **KEDA** (HTTP and Service Bus triggers)
- 🐳 **Docker**: containerized services deployed to Azure

## 🧩 How I solve problems

1. **Understand the pain**: what's slow, risky, or manual?
2. **Design the solution**: clean APIs, clear data models, and simple architecture.
3. **Automate it**: CI/CD and Infrastructure as Code instead of click-ops.
4. **Make it safe**: security scanning, quality gates, approvals, and rollback plans.
5. **Document it**: runbooks and guides so the whole team can use it.
